Then add `export`/`import` statements to each module per the REQUIRED IMPORTS

## Strategy B — shared-IIFE concatenation (no bundler, zero call-site edits)

Concatenate the files in the order above into one file wrapped in a single
(function(){ 'use strict'; ...concat... })() IIFE. Because the original was a
single closure, bare-name cross-references continue to resolve. Example build:

    { echo '(function(){ \x27use strict\x27;'; \
      for f in core state schema ... boot; do cat site/editor/$f.js; done; \
      echo '})();'; } > site/editor.bundle.js

(strip the per-file header scaffolds before concatenating, or leave them as
comments — they are comment-blocks only.)
