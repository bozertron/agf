# Icons

Ten single-ink line icons on a 24px grid, 1.5px stroke, round caps and joins, delivered in brass (#B8860B). Inline and set `stroke` to `brass`, `brass-text` or `ink-faint`; use at 16, 20 or 24px beside a label with a `space-8` gap. Extend the set at the same stroke and grid; no filled icons, no emoji.
