# Logos

All four are delivered in brass (#B8860B, with #D4A234 for the badge's ring). Recolour by inlining the SVG and setting its fill or strokes; as an `<img>` they stay brass.

- `agf-mark.svg` — the letters AGF set from Monoton outlines. The primary mark; 24px / 8 mm cap height minimum.
- `agf-lockup.svg` — the mark with "All Grounds Floating" in Poiret One justified to its width. Use at 64px mark width and above; below that, the mark alone.
- `agf-seal.svg` — two hairline rings, sixty dial ticks, the mark. Gifts, foils, debossing, etching; 72px / 24 mm minimum.
- `floating-ground.svg` — the Floating Ground badge: IEC earth symbol in a broken orbital ring. Once per object; 24px / 6 mm minimum, single ink below 48px.
