# Badge

A pill (`radius-pill`, the one place pills are allowed) of uppercase 11px text with a 6px lamp: **live** is a `live` fill with `on-signal` text and a pulsing lamp for ON AIR, **brass** is `brass-text` with a `brass` lamp for REC and armed states, **nominal** lights a `signal-nominal` lamp for link, lock and sync, the default is a `moss` lamp for idle, and **plain** drops the lamp for facts like sample rate. The word always travels with the colour. One live badge per screen, and never as a button.
