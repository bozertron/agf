# Input

Text inputs and selects are 44px wells of `surface-sunken` with a `brass-hairline` border and `radius-2`, the label an uppercase `eyebrow` in `ink-faint` above and a `hint` in 13px below. Hover and focus move the border to `line-strong`; keyboard focus adds the `focus-ring` outline. Invalid fields take a `signal-clip` border and say what is wrong in the hint, in words. Placeholders are examples in `moss`, never instructions. The consumer provides label, hint and value; labels are always visible, never placeholder-only.
