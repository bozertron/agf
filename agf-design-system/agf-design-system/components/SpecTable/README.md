# SpecTable

Specifications in three columns: parameter in `ink-muted` weight 500, value with tabular figures in `ink` and its unit in `ink-faint`, and the measurement conditions, because a number without conditions is advertising. The header row is `eyebrow` style over a `border-rule` in `brass`; body rows divide with `brass-hairline` and stripe with `surface-sunken`. Units use the proper symbols (Ω, µ, dBu) and a thin space before them. The consumer provides rows; keep tables under ten rows a block and never merge cells.
