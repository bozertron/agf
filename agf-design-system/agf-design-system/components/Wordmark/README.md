# Wordmark

The lockup: the letters **AGF** in Monoton (`mark`) with "All Grounds Floating" in Poiret One (`strapline`) justified to the mark's width beneath it. Brass (`brass`) on `surface-deep` is the primary form; on paper use the lockup in `forest` or `ink`; never in two colours. The consumer provides nothing but the size variant (`--lg` 96px mark with a 15px strapline, default 64px with a 10px strapline, `--sm` 24px mark alone). The strapline is set at 0.156× the mark size so its tracked width equals the mark's; below a 64px mark that makes it unreadable, so smaller uses carry the mark alone, and print uses `assets/Logos/agf-lockup.svg`. Clear space all round equals the cap height of the mark. Do not set any word other than AGF in Monoton, do not outline, shadow or gradient the mark, and do not place it over imagery without a `scrim`.
