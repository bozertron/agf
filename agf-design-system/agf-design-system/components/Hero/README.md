# Hero

The web hero: `surface-deep` with the TraceField and grain, a `strapline-small` in Poiret One `brass` as the one reserved line, a `mega`-class headline in Commissioner 200 (72-96px, two lines at most), a primary and a quiet Button. Photography, when used, sits beneath a `scrim` and the trace field is dropped so there is one texture, not two. Content enters with the scroll-reveal motion from 03-motion.md (rise `space-24` and fade over 700ms on `--ease-damped`, `cubic-bezier(0.16, 1, 0.3, 1)`, children staggered 60ms) and the background drifts at 0.6× scroll for parallax; under `prefers-reduced-motion` the parallax stops and reveals become 200ms fades. The consumer provides strapline, headline, two actions and optional imagery; no carousel, no autoplaying video with sound.
