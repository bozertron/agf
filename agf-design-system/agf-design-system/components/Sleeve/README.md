# Sleeve

Packaging and gifts: the outer sleeve is `surface-deep` board with the trace field printed in a single brass spot colour (a `surface-deep` band is always set in the Midnight theme: wrap it in `data-theme="midnight"` so every token inside resolves to its dark value, in both themes) at `opacity-trace` equivalent (a 30% tint), the lockup top-left, the Seal top-right, and the product line in `strapline-small` at the foot with the series number in `caption`. Interiors are Daylight: `surface` bone stock, `ink` text, one `trace` rule, no pattern. Luxury gifts (leather, coasters, pens, a notebook) take the Seal blind-debossed or in brass foil, never the full lockup, and never any copy beyond the strapline. Metallic ink is a true brass (PMS 871 C equivalent), not yellow; the forest is PMS 5535 C equivalent. The consumer provides product line, series and the dedication line.
