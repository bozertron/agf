# Seal

A round seal for gifts, packaging and etched hardware: two hairline rings, sixty dial ticks and the mark at the centre, all in a single ink. Use `brass` on dark grounds, `brass-text` on paper, or press it as `on-brass` into a solid brass disc (foil, enamel pin, coaster). Minimum 24 mm in print and 72px on screen; the ticks disappear below that. The consumer provides the ink colour via CSS `color` when inlining the SVG, or uses `assets/Logos/agf-seal.svg` as an image where it is already brass.
