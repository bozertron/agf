# Faceplate

How the system lands on metal. The plate is `surface-deep` (black-green anodised aluminium, matte) and, like every always-dark application, is wrapped in `data-theme="midnight"` so lamps, troughs and knob caps keep their Midnight values on a Daylight page, edged with a `brass-hairline` chamfer and four countersunk screws; legends are `micro` uppercase screen-printed in `brass`, 2 mm cap height minimum, aligned to an 8 mm grid; the mark sits left with the model name in `strapline-small` beneath it; sections divide with a hairline engraved rule. Jacks are brass-ringed, lamps are 3 mm and show only `brass-glow` (on) or `live` (clip, on air); the meter is the Meter component in LEDs. Knobs are the Knob component machined. No white, no blue LEDs, no silkscreen box outlines. The consumer provides the module layout; one plate carries one mark.
